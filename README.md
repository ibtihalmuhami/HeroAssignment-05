

answer-1----------
var, let, const: var is the backdated way that often causes bugs. Use let if you need to change the value later, and const for values that stay the same .


answer-2--------------
Spread operator (...): It takes all the items out of one array or object and spreads them into another one.


answer-3---------------
map, filter, forEach: forEach just loops through a list without creating anything new. map takes a list, changes every item, and gives a brand new list. filter checks a list against a rule and only keeps the items that pass.


answer-4-----------------
Arrow function: A shorter, cleaner way to write functions using => instead of the word function. It makes  code much easier to read.


answer-5----------------------
Template literals: Writing strings using backticks (`) instead of quotes. It lets you plug variables directly into text using ${variable} without needing plus signs.
